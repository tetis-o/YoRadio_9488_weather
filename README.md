# Логарифмическая регулировка громкости
В исходной реализации использовалась **линейная** зависимость уровня выходного сигнала от значения регулятора громкости.
Это приводило к тому, что при значении громкости 1 уровень сигнала был слишком высоким (около 0.4% от максимума), что не позволяло установить достаточно тихий уровень.
Человеческое ухо воспринимает громкость **логарифмически** — для субъективного удвоения громкости требуется увеличение мощности сигнала примерно в 10 раз.
В файле `src/audioI2S/Audio.cpp` функция `computeLimit()` изменена для использования степенной зависимости.
## Настройка
Параметр `GAMMA` находится в файле [src/audioI2S/Audio.cpp:5417](src/audioI2S/Audio.cpp#L5417):
- **2.0** — умеренная кривая
- **2.5** — рекомендуемое значение
- **3.0** — более резкое снижение малых значений

Чем больше значение `GAMMA`, тем меньше уровень при малых значениях регулятора.
## Примечание

Изменение применяется только к аудио через I2S (ESP32). Для VS1053 логарифмическая коррекция уже была реализована через макрос `VS1053VOL` в файле `src/audioVS1053/audioVS1053Ex.h`.
